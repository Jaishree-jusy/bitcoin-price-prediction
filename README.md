# ₿ Bitcoin Price Prediction Dashboard

> An interactive machine learning dashboard that predicts Bitcoin prices from market data and presents the results through a simple, user-friendly interface.

## 🚀 About the Project

Bitcoin prices are highly dynamic and influenced by multiple market factors. This project explores how historical market indicators can be used to build a machine learning model for Bitcoin price prediction.

The project combines a trained machine learning model with an interactive Streamlit dashboard, allowing users to enter market values and obtain a predicted Bitcoin price.

## ✨ Features

- 📊 Interactive Bitcoin market dashboard
- 🤖 Machine-learning-based price prediction
- 📥 User input for:
  - Open Price
  - High Price
  - Low Price
  - Close Price
  - Trading Volume
- ⚡ One-click sample market data
- 📈 Interactive visualizations
- ✅ Input validation
- 🎨 Clean and responsive dashboard interface
- 💾 Pre-trained model included for prediction
