# ₿ Bitcoin Price Prediction Dashboard

> An interactive machine learning dashboard for predicting Bitcoin prices from market data using a trained ML model.

---

## 🚀 About the Project

Bitcoin is a highly dynamic and volatile digital asset, making price prediction an interesting machine learning problem.

This project uses historical Bitcoin market indicators to build a machine learning-based prediction system. The trained model is integrated into an interactive Streamlit dashboard where users can enter market data and generate a predicted Bitcoin price.

The project combines **Machine Learning, Python, Data Analytics, and Interactive Visualization** into a simple web application.

- 📊 Interactive Bitcoin prediction dashboard

## 🧠 How It Works

The application follows a simple prediction pipeline:

```text
Bitcoin Market Data
        ↓
    User Input
        ↓
 Feature Preparation
        ↓
  Trained ML Model
        ↓
 Bitcoin Prediction
        ↓
 Interactive Dashboard
```

The user enters five market indicators:

- **Open Price**
- **High Price**
- **Low Price**
- **Close Price**
- **Trading Volume**

The application loads the trained model from `bitcoin_model.pkl` and uses the provided market data to generate a prediction.

## 📊 Input Parameters

The dashboard accepts five important market indicators.

### Open Price
The Bitcoin price at the beginning of the trading period.

### High Price
The highest Bitcoin price recorded during the trading period.

### Low Price
The lowest Bitcoin price recorded during the trading period.

### Close Price
The Bitcoin price at the end of the trading period.

### Volume
The amount of Bitcoin traded during the period.

These values are provided to the trained machine learning model to generate the prediction.

## 💻 Run the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/Jaishree-jusy/bitcoin-price-prediction.git
```

### 2. Navigate to the project

```bash
cd bitcoin-price-prediction
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the environment

**Windows:**

```bash
venv\Scripts\activate
```

**macOS / Linux:**

```bash
source venv/bin/activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Start the application

```bash
streamlit run app.py
```

The dashboard will open in your browser.

## 🎯 How to Use

1. Open the Bitcoin Price Prediction Dashboard.
2. Enter the required market values.
3. Or click **Use Sample Market Data** to automatically fill sample values.
4. Click **Predict**.
5. The trained ML model processes the input.
6. View the generated Bitcoin price prediction.
